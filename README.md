# 偏遠救護接駁點建議系統

A 分隊出勤沒有 TP 時，請 B 分隊支援，兩隊在預設的接駁點碰面後一起送醫。
本系統讓 A 分隊同仁在案發現場用手機**逼一下 NFC（或掃 QR Code）**，就能看到：

- **建議接駁點**：讓 A、B 兩隊最快碰頭（B 分隊越早上車協助給藥越好）
- 預估碰頭時間、哪一隊先到、要等多久、預估到院時間
- 一鍵 Google 地圖導航，以及一鍵把接駁點傳給 B 分隊（LINE）
- 備案接駁點（第 2、3 名）

> 本系統是決策輔助工具，實際接駁點以指揮中心或帶隊官指示為準。

---

## 計算方式

對每一個啟用中的接駁點 T：

```
A 抵達 = 案發現場 → T 的行車時間
B 抵達 = B 分隊準備時間（預設 2 分）＋ B 分隊駐地 → T 的行車時間
碰頭時間 = max(A 抵達, B 抵達)          ← 主要排序依據
送醫總時間 = 碰頭時間 ＋ T → 醫院的行車時間
```

1. 先找出**碰頭時間最短**的接駁點。
2. 碰頭時間與最短者相差在「相近門檻」（預設 3 分鐘）以內的接駁點，改以**送醫總時間較短**者優先。
3. 其餘接駁點依碰頭時間排序，作為備案。

行車時間來源（自動切換）：

| 順序 | 服務 | 需要 | 說明 |
|---|---|---|---|
| 1 | Google Routes API | 金鑰（`js/config.js`） | 含即時路況，最準 |
| 2 | OpenRouteService | 免費金鑰（選填） | 開放圖資，無路況 |
| 3 | OSRM 公用伺服器 | 不需要 | 開放圖資，無路況，最後備援 |

前一個沒有設定或失敗，會自動換下一個，畫面最下方會註明這次用的是哪個來源。

## 網址參數（寫進 NFC／QR Code）

| 參數 | 意義 | 範例 |
|---|---|---|
| `a` | 出勤分隊代碼（必填） | `?a=BL` |
| `b` | 預先指定支援分隊（選填，指揮中心傳連結時用） | `?a=BL&b=FX` |
| `h` | 預先指定醫院（選填） | `?a=BL&h=H01` |

網址可以在 **管理工具頁（tools.html）** 直接產生，並附 QR Code。

## 一、建立 Google 試算表（地點資料）

1. 用要交接的帳號（建議救護科公務帳號）建立一份新的 Google 試算表。
2. 建立四個分頁，**名稱必須完全相同**：`分隊`、`接駁點`、`醫院`、`設定`。
   - 最快的方法：把 `data/sample/` 裡的四個 CSV 檔分別用「檔案 → 匯入 → 上傳 → 插入新工作表」匯入，再把分頁改名。
3. 欄位說明（第一列為標題）：

**分隊**

| 代碼 | 名稱 | 座標 | 轄區醫院代碼 | 啟用 | 備註 |
|---|---|---|---|---|---|
| BL | 巴陵 | 24.678049, 121.384509 | H01,H02 | 是 | |

**接駁點**

| 代碼 | 名稱 | 座標 | 啟用 | 備註 |
|---|---|---|---|---|
| T01 | 羅浮橋 | 24.800293, 121.366971 | 是 | 橋頭停車處 |

**醫院**

| 代碼 | 名稱 | 座標 | 啟用 | 備註 |
|---|---|---|---|---|
| H01 | 國軍桃園總醫院 | 24.877505, 121.234848 | 是 | |

**設定**

| 項目 | 值 | 說明 |
|---|---|---|
| B分隊準備時間(分鐘) | 2 | |
| 碰頭時間相近門檻(分鐘) | 3 | |
| 開放圖資時間倍率 | 1.0 | 免費圖資常低估山路時間，可調成 1.2 等 |

填寫規則：

- **代碼**：英文字母開頭（例如 `BL`、`T01`、`H01`），會出現在 NFC 網址裡，**寫好標籤後就不要再改**。
- **座標**：在 Google 地圖上對地點按右鍵，第一行就是「緯度, 經度」，點一下即可複製，貼到座標欄。也可以用管理工具頁的地圖點選。
- **轄區醫院代碼**：多家用逗號分隔，畫面會依此順序列出，第一家為預設。留空表示列出全部醫院。
- **啟用**：填「否」就暫時停用（例如道路中斷的接駁點），留空或「是」為啟用。
- 同一欄請保持同一種格式（例如座標欄都填文字座標），避免 Google 匯出時把格式不同的格子讀成空白。

4. 右上角「共用」→「一般存取權」改為 **知道連結的任何人 → 檢視者**（網頁才讀得到；編輯權限只開給管理者）。
5. 複製試算表網址中 `/d/` 和 `/edit` 之間那一串 ID，填到 `js/config.js` 的 `spreadsheetId`。
6. 開啟管理工具頁的「目前資料檢查」，確認沒有警告。之後修改試算表，大約 5 分鐘內網頁就會讀到新資料。

## 二、部署到 GitHub Pages

1. 把本專案推到 GitHub 儲存庫（免費方案的 GitHub Pages 需要**公開**儲存庫；內容只有地點座標與程式，沒有機敏資料）。
2. 儲存庫 → Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾 `/ (root)` → Save。
3. 約 1 分鐘後網址會是 `https://<帳號>.github.io/<儲存庫名稱>/`。

> ⚠️ **NFC 標籤裡寫的是固定網址。** 如果之後把儲存庫搬到別的帳號，網址會改變，標籤就要全部重寫。
> 建議正式大量寫標籤前，先決定最終放在哪個帳號（例如建立救護科專用的 GitHub 組織帳號）。

## 三、製作 NFC 標籤與 QR Code

1. 打開 `https://<網站>/tools.html`，選擇出勤分隊，就會產生網址與 QR Code。
2. 寫入 NFC：
   - **Android**：用 Chrome 開管理工具頁 →「直接寫入 NFC 標籤」→ 把標籤貼近手機背面。
   - **iPhone**：安裝免費 App「NFC Tools」→ 寫 → 新增記錄 → URL → 貼上網址 → 寫。
3. 建議使用 NTAG215 規格的防水貼紙，貼在救護車固定位置，旁邊再貼同一網址的 QR Code 作為備援。
4. 管理工具頁的「全部分隊 QR Code」可以一次列印所有分隊。
5. 同仁也可以在手機瀏覽器開啟網址後選「加到主畫面」，之後點圖示就能直接開啟。

## 四、申請 Google 路線金鑰（選用，提升準確度）

沒有金鑰也能用（自動改用免費開放圖資），但 Google 有即時路況，比較準確。

1. 到 [Google Cloud Console](https://console.cloud.google.com/) 用公務帳號建立專案，並綁定帳單（需要信用卡）。
2. 「API 和服務 → 程式庫」啟用 **Routes API**。
3. 「憑證 → 建立憑證 → API 金鑰」，並立刻設定限制：
   - **應用程式限制**：網站（HTTP 參照網址），加入 `https://<帳號>.github.io/*`
   - **API 限制**：只勾 Routes API
4. 「配額」裡把 Routes API 的每日要求數上限設為較小的數字（例如每天 100 次），超過就自動停用，改用免費圖資，**保證不會被收費**。
5. 「帳單 → 預算與快訊」設定每月 1 美元預算提醒。
6. 把金鑰填到 `js/config.js` 的 `googleApiKey`。

每次計算約使用 3 × 接駁點數量 的路線元素（例如 9 個接駁點約 27 個），以偏遠接駁的使用頻率，預期在 Google 每月免費額度內。實際免費額度與計價以 Google 官方公告為準。

> 網頁金鑰一定會出現在瀏覽器端，所以第 3、4 步的限制很重要：限制後別人拿到金鑰也無法從其他網站使用。

## 本機預覽與測試

```bash
# 預覽（需要用 http 開啟，不能直接雙擊 index.html）
python -m http.server 8000
# 瀏覽器開 http://localhost:8000/?a=BL

# 單元測試（Node.js 18 以上，不需要安裝任何套件）
npm test
```

本專案為純前端網頁，不需要安裝任何 Python 或 npm 套件；地圖（Leaflet）與 QR Code 元件由 CDN 載入。

## 檔案結構

```
index.html            主頁（同仁逼 NFC 後看到的頁面）
tools.html            管理工具：產生 NFC/QR 網址、座標點選、資料檢查
js/config.js          系統設定（試算表 ID、金鑰、預設參數）← 部署時只改這裡
js/types.js           資料結構定義
js/dataSource.js      讀取試算表／示範資料、資料檢查
js/routing.js         路線服務（Google → ORS → OSRM 自動切換）
js/planner.js         接駁點排序邏輯（純函式）
js/app.js             主頁控制
js/resultView.js      結果畫面
js/mapView.js         地圖
js/format.js          時間、連結、分享文字格式
data/sample/*.csv     示範資料（也是試算表匯入範本）
tests/                單元測試
docs/CHANGELOG.md     變更紀錄
```
